#The Data Engine

The data engine is an analytics and systems integration project designed to simulate a manufacturing production line and provide an actionable "what if" testing environment for operations managers. 

## Planned Architecture

- `simulator/` - Python factory-floor simulation and event generation
- `database/` - SQL schema, queries, views, and database configuration
- `api/` - Application programming interface connecting services and clients
- `dashboard/` - React-based manufacturing analytics dashboard
- `excel/` - Excel, Power Query, and reporting integration
- `hardware/` - Arduino and physical IoT integration
- `docs/` - Architecture notes, diagrams, and project documentation
- `tests/` - Automated tests

## Project Goals 

This project will explore:

- Python
- SQL
- JavaScript
- React
- REST APIs
- Excel and Power Query
- Manufacturing Analytics
- Lean manufacturing metrics
- IoT / Arduino integration
- Full-stack systems integration
